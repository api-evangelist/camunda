Camunda 8.10.0-alpha1 introduces several major capabilities for process orchestration including a Processes MCP Server and new MCP start event element template that makes every deployed process directly callable as an MCP tool. The release also features an enhanced variable viewer in Operate, execution listener configuration headers, native ABBYY support for document processing, and a Camunda-provided LLM to streamline AI agent development without requiring external credentials.
